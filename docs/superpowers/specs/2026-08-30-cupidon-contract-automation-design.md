# 큐피돈 아이폰 스냅 계약서 발송 자동화 — Design Spec

**작성일:** 2026-08-30
**작성자:** 박채진 (chaejin.park@myrealtrip.com)
**목표:** 카카오톡 등으로 계약 문의가 들어왔을 때, 고객이 링크 하나로 상담-견적-계약-서명까지 원스톱 처리할 수 있는 시스템 구축.

---

## 1. 배경 & 목적

- 현재는 문의가 오면 사장님이 수동으로 상품/할인/옵션을 조합해 견적을 계산하고, 계약서 4종 중 하나를 골라 필드를 채워 카톡으로 전송한다.
- 상품 브로슈어와 계약서 문구가 어긋나 있는 부분도 있어 오류 여지가 크다.
- **자동화 목표:** 고객이 URL 링크에서 답변만 하면 → 견적/계약서/서명까지 완료 → 사장님 이메일로 서명본 PDF 자동 도착.

## 2. 사용자 시나리오

1. **고객이 카톡으로 "스냅 예약 문의드립니다" 라고 연락.**
2. 사장님이 준비된 링크(`https://<domain>/cupidon-contract`)를 전달.
3. 고객이 링크 클릭 → 폼 진행:
   - Step1 기본정보 → Step2 행사정보 → Step3 상품선택 → Step4 옵션 → Step5 할인 → Step6 견적확인 → Step7 서명 → Step8 완료.
4. 서명 완료 시:
   - 고객 화면에서 계약서 PDF 자동 다운로드.
   - 사장님 이메일로 서명 완료 PDF 자동 발송(EmailJS).
5. 사장님은 이메일 확인 후 계약금 100,000원 입금 안내로 마무리.

## 3. 스코프

### In-scope
- 상품 4종 (1인 스페셜 / 2인 프리미엄 / 스튜디오&가봉 / 돌스냅) 견적·계약서 자동 생성.
- 할인 5종 자동 적용.
- 옵션·출장비·돌스냅 아이폰 단독 추가금 반영.
- 캔버스 서명 → PDF 삽입.
- EmailJS 통한 사장님 이메일 자동 전송.
- GitHub Pages 무료 호스팅.

### Out-of-scope (초기 버전)
- 계약금 결제 시스템 연동 (수동 계좌이체 안내로 유지).
- 관리자 대시보드(계약 이력 조회) — 필요시 v2.
- 다국어 지원.
- 카카오 알림톡 자동 발송 (유료 API, v2 검토).
- 후기 실제 작성 여부 검증 & 사후 정산 자동화 (수동 유지).

|---|---|---|---|---|---|---|---|---|
| `special` | 1인 스페셜 | 350,000 | 800장 | 10장 | 20장 | 10개 | 땡큐 1장 | 예식 60분 전~플라워샤워~원판 |

| `dol` | 돌스냅 | 300,000 | 500장 | 10장 | 10장 | 20개 | 감사카드 1장 | 2시간 |

### 4.2 할인 규칙 (2종 분리)

**A. 즉시 적용 할인 (계약 시점에 총액에서 바로 차감)**

| 코드 | 이름 | 금액 | 적용 대상 | 비고 |
|---|---|---|---|---|
| `sameDay` | 당일 계약 할인 | -30,000 | 전상품 | 문의 당일 계약 확정 시 |
| `portrait` | 초상권 활용 동의 | -20,000 | 전상품 | 큐피돈이 마케팅에 사진 활용 동의 |
| `partner` | 짝꿍 할인 | -20,000 | 스페셜·프리미엄만 | **짝꿍코드 필수 입력**, 1회 적용 |

**짝꿍코드 검증 규칙:**
- 체크박스 선택 시 코드 입력 필드가 노출되고 필수값으로 전환.
- 코드는 텍스트(대문자+숫자 자유형식, 예: `KHR2026`) — 서버가 없어 실시간 유효성 검증은 불가하므로 **입력 여부만 필수 검증**.
- 입력된 코드는 이메일 페이로드·계약서 하단·사장님 이메일 본문에 **원문 그대로** 표기되어 사장님이 사후 확인 가능.
- 미입력 시 다음 스텝 진행 불가.

**B. 후기 약속 할인 (계약 시엔 "약속"으로만 표시, 실제 작성 후 잔금에서 차감)**

| 코드 | 이름 | 금액 | 적용 대상 | 비고 |
|---|---|---|---|---|
| `blogPromise` | 블로그 계약 후기 약속 | -10,000 (약속) | 전상품 | 후기 URL 전달 시 잔금에서 차감 |
| `cupidonPromise` | 큐피돈 이용 후기 약속 | -10,000 (약속) | 전상품 | 후기 작성·전달 시 잔금에서 차감 |

**계약서 표기:** A는 총액에 반영. B는 계약서 하단에 "**추후 정산 가능:** 블로그 후기 -10,000 / 큐피돈 후기 -10,000 (작성·전달 시 잔금에서 차감)"으로 별도 표기.

### 4.3 추가 옵션

**스페셜·프리미엄 (예식):**
| 코드 | 이름 | 금액 |
|---|---|---|
| `finalPlus5` | 최종본 추가 5장 | +50,000 |
| `colorPlus10` | 색보정 추가 10장 | +50,000 |
| `part2` | 2부 촬영 추가 | +70,000 |
| `pyebaek` | 폐백 촬영 추가 | +50,000 |

**스튜디오·돌스냅:**
| 코드 | 이름 | 금액 |
|---|---|---|
| `finalPlus5` | 최종본 추가 5장 | +50,000 |
| `part2Half` | 2부 촬영 추가 (30분) | +50,000 |

### 4.4 출장비

| 지역 코드 | 이름 | 금액 | 비고 |
|---|---|---|---|
| `seoul` | 서울 | 0 | 기본 |
| `gyeonggi_incheon` | 경기·인천 | +50,000 | |
| `pyeongtaek` | 평택 | +70,000 | |
| `other` | 그 외 | (문의) | 폼에서 "별도 문의" 배지 표시, 견적 미확정 |

### 4.5 특수 조건

- **돌스냅 아이폰 단독 촬영:** 메인스냅(전문 사진사) 없이 큐피돈 아이폰 촬영만 진행 시 **+50,000**. 폼에 "메인스냅이 함께 있나요?" 질문. 아니면 자동 가산.

### 4.6 최종 금액 공식

```
immediateDiscount = sum(A그룹 즉시할인)   // 음수 합계
promiseDiscount   = sum(B그룹 후기 약속)  // 음수 합계, 계약서엔 별도 표기

totalPrice = basePrice
           + travelFee
           + sum(selectedOptions)
           + (product == 'dol' && !hasMainSnap ? 50000 : 0)
           + immediateDiscount

deposit           = 100,000  (고정)
balance           = totalPrice - deposit
balanceAfterReviews = balance + promiseDiscount   // 참고용 표시
```

**Edge case:** `region == 'other'` 인 경우 견적 표시란에 "출장비 별도 문의 (미포함)"를 명시하고, 계약서에도 동일 문구 삽입. 총액은 출장비 제외 금액으로 표시.

## 5. 시스템 아키텍처

### 5.1 구성

```
[고객 브라우저]
    │
    ├─ index.html (Step 1-8 SPA)
    ├─ Tailwind CSS (CDN)
    ├─ signature_pad (서명 캔버스)
    ├─ jsPDF + jspdf-autotable (PDF 생성)
    ├─ NanumGothic.ttf (한글 폰트, base64 임베드)
    └─ EmailJS SDK (이메일 발송)
                │
                ▼
        [EmailJS 서버]  ──▶ 사장님 Gmail
```

- **호스팅:** GitHub Pages (`https://<username>.github.io/cupidon-contract/`)
- **서버 없음:** 모든 로직은 브라우저에서 실행. 데이터는 EmailJS를 경유해 사장님 이메일로만 전달.

### 5.2 컴포넌트 책임 분리

| 파일 | 책임 |
|---|---|
| `index.html` | 폼 마크업 + Step 컨테이너 |
| `js/config.js` | 상품/할인/옵션 상수 (Source of Truth) |
| `js/pricing.js` | 금액 계산 순수 함수 (단위 테스트 가능) |
| `js/form.js` | 폼 상태 관리, Step 이동, 조건부 필드 노출 |
| `js/templates.js` | 계약서 4종 텍스트 템플릿 |
| `js/pdf.js` | jsPDF로 계약서 렌더링 (상품 표, 서명 이미지 삽입) |
| `js/email.js` | EmailJS 초기화 + 발송 |
| `js/app.js` | 진입점, 모듈 조립 |

**설계 원칙:** `pricing.js`, `templates.js`는 순수 함수/데이터로 유지 → 브라우저 콘솔에서 직접 테스트 가능. UI 변경이 로직에 영향 없도록.

## 6. 폼 UX 상세

### Step 1. 기본 정보
- 계약자 성함 (텍스트, 필수)
- 연락처 (전화번호, 필수, `010-0000-0000` 자동 포맷)

### Step 2. 행사 정보
- 예식일자 (date picker, 필수)
- 예식시간 (time picker, 필수)
- 예식장·장소명 (텍스트, 필수)
- 출장지역 (라디오: 서울 / 경기·인천 / 평택 / 그 외)
  - "그 외" 선택 시: "출장비는 별도 문의 후 안내드립니다" 안내 배너

### Step 3. 상품 선택
- 4종 카드 UI (라디오 선택)
- 각 카드에 정가, 포함 내역 표시

### Step 4. 추가 옵션
- 선택 상품에 따라 옵션 항목 동적 노출
- **돌스냅 선택 시:** "예식 당일 메인스냅(사진사)이 함께 있나요?" (예/아니오) → 아니오면 +50,000 자동 가산

### Step 5. 할인 적용
- **즉시 적용 (총액에서 바로 차감)** 섹션:
  - 당일 계약 -30,000 (체크박스)
  - 초상권 활용 -20,000 (체크박스)
  - 짝꿍코드 사용 -20,000 (스페셜/프리미엄일 때만 노출)
    - **체크 시 하단에 "짝꿍코드" 텍스트 입력창 노출 (필수)**
    - placeholder: "예: KHR2026"
    - 입력값은 계약서·이메일에 그대로 표기
- **후기 약속 (잔금 정산 시 차감)** 섹션:
  - 블로그 계약 후기 작성 약속 -10,000 (체크박스)
  - 큐피돈 이용 후기 작성 약속 -10,000 (체크박스)
- 각 항목 옆에 금액 표시. 하단에 "약속 할인은 실제 후기 URL을 전달하시면 잔금에서 차감됩니다" 안내.

### Step 6. 견적 확인
- 실시간 계산 결과 표시:
  - 상품 정가
  - 출장비
  - 추가 옵션 (선택된 것만)
  - 즉시 할인 (선택된 것만)
  - **총액 (합계)**
  - **계약금 100,000 (고정)**
  - **잔금 (총액 - 100,000)**
  - **[참고] 후기 약속 반영 시 잔금:** (총액 + 후기 약속 할인 - 계약금)
- "이 금액으로 계약을 진행합니다" 확인 체크박스

### Step 7. 서명
- 계약서 요약 (조건 요약 텍스트)
- "위 계약 내용을 충분히 이해했으며 동의합니다" 체크박스
- 서명 캔버스 (`signature_pad`) — 손가락/마우스 서명 가능
- "다시 서명" 버튼

### Step 8. 완료
- 서명 완료 → 자동으로:
  1. PDF 생성 및 다운로드 (`큐피돈_계약서_{상품}_{성함}_{YYYYMMDD}.pdf`)
  2. EmailJS로 사장님 이메일에 PDF 첨부 발송
- "계약이 완료되었습니다. 계약금 100,000원을 아래 계좌로 입금해주세요."
- 계좌 정보 표시
- 사장님 카톡 연락처 안내

## 7. 계약서 PDF 스펙

### 7.1 공통 레이아웃

```
[페이지 1]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
     큐피돈 아이폰 스냅 계약서
       (적용된 할인 라벨)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 상품 구성
┌─────────┬─────────────┬─────────────┐
│ 상품명   │ 내용         │ 추가 옵션    │
├─────────┼─────────────┼─────────────┤
│ (동적)  │ (브로슈어)   │ (선택된 것) │
└─────────┴─────────────┴─────────────┘

2. 결제 및 환불 안내
- 잔금은 예식 7일 전까지 완납
- 계약금 100,000원 입금으로 확정
- 확정일 기준 14일 이내: 계약금 100% 환불
- 확정일 기준 14일 이후: 계약금 환불 불가
- 천재지변: 환불 가능
- 단순 변심·웨딩홀 귀책: 환불 불가
- 큐피돈 귀책: 200% 환불

3. 데이터 전달 및 보관 안내
(상품별로 다름 — templates.js에서 정의)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━
상기 내용에 동의합니다.

계약금: 100,000원   잔금: XXX,XXX원
용역 공급자: 큐피돈 스냅

예식일: YYYY년 MM월 DD일 오전/오후 HH시
장소: (예식장명)
계약자 성함: (성함)
연락처: (전화)

서명: [서명 이미지]           계약일: YYYY. MM. DD.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 7.2 상품별 데이터 전달 안내 차이

- **스페셜:** 원본 24시간 이내, 보정본 셀렉일 기준 7일 이내, MyBox 링크
- **프리미엄:** 원본 24시간 이내, 최종본·색보정본 14일 이내, MyBox 링크
- **스튜디오:** 원본 24시간 이내, 보정본 셀렉일 기준 7일 이내, 네이버 드라이브
- **돌스냅:** 원본 24시간 이내, 보정본 셀렉일 기준 7일 이내, 네이버 드라이브

### 7.3 계약서 상단 라벨

적용된 할인에 따라 상단 부제를 자동 생성:
- 예: "(당일계약, 초상권, 짝꿍 할인)"

## 8. EmailJS 세팅

### 8.1 세팅 절차 (README에 안내)
1. https://emailjs.com 무료 가입
2. Email Service 연결 (Gmail 추천, OAuth)
3. Email Template 생성:
   - `{{customer_name}}, {{product}}, {{event_date}}, {{total}}, {{deposit}}, {{balance}}` 등 변수
   - 첨부파일: `{{pdf_attachment}}` (base64)
4. Public Key, Service ID, Template ID를 `js/email.js` 상단에 붙여넣기

### 8.2 발송 페이로드

```js
{
  to_email: "chaejin.park@myrealtrip.com",
  customer_name: "홍길동",
  customer_phone: "010-1234-5678",
```

## 9. 에러 처리

| 상황 | 처리 |
|---|---|
| 필수 필드 미입력 | Step 이동 버튼 비활성화 |
| 짝꿍할인 체크 후 코드 미입력 | 다음 스텝 진행 불가, 입력창 강조 |
| 출장지역 "그 외" | 견적 미확정 배지 표시, 계약서에도 동일 문구 |
| 서명 없이 완료 시도 | 서명 캔버스에 강조 테두리, alert |
| EmailJS 발송 실패 | PDF 다운로드는 성공하므로 화면에 "이메일 발송에 실패했습니다. PDF를 카톡으로 직접 보내주세요" 안내 + 사장님 카톡 링크 노출 |
| PDF 생성 실패 (폰트 로드 실패 등) | 재시도 버튼 + 콘솔 로그 |

## 10. 테스트 계획

- **pricing.js 단위 테스트:** 각 상품 × 각 할인 조합 × 옵션 × 출장비의 최종 금액 검증 (브라우저 콘솔에서 실행 가능한 형태로 작성).
- **템플릿 렌더링 검증:** 4개 상품 × 대표적 옵션 조합 3-4개 → PDF 생성 후 육안 검토.
- **크로스 브라우저:** 크롬(안드로이드), Safari(iOS), 데스크톱 크롬 최소 3환경.
- **서명 캔버스:** 모바일 터치, 데스크톱 마우스 모두 동작 확인.

## 11. 배포 & 유지보수

- **Repo:** GitHub 개인 리포지토리 `cupidon-contract` (Public — GitHub Pages 무료 티어).
- **배포:** `main` 브랜치 push 시 자동 배포.
- **가격/옵션 변경:** `js/config.js`만 수정 → 커밋 → 자동 반영.
- **계약서 문구 변경:** `js/templates.js` 수정.
- **EmailJS 크레딧:** `js/email.js`의 3개 키 값만 관리 (README에 위치 명시).

## 13. 성공 기준

1. 고객이 링크 클릭 후 3분 이내에 계약 완료 가능.
2. 사장님이 이메일로 서명 완료 PDF를 즉시 수신.
3. 견적 계산에 수작업 계산 오류 0건.
4. 상품 4종 × 할인 5종 × 옵션 여러 조합에서 모두 정확한 금액 산출.
5. 월 200건 이내 EmailJS 무료 티어로 운영 가능.
